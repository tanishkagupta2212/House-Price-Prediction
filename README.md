# House Price Prediction Using Machine Learning

## Objective
To predict house prices using machine learning models and compare their performance.

## Dataset
California Housing Dataset

## Models Used
- Linear Regression
- Ridge Regression
- Decision Tree Regressor

## Evaluation Metrics
- RMSE
- R² Score

## Results

| Model | RMSE | R² Score |
|--------|--------|--------|
| Linear Regression | 0.745581 | 0.575788 |
| Ridge Regression | 0.745554 | 0.575819 |
| Decision Tree | 0.724234 | 0.599732 |

## Best Model
Decision Tree Regressor

## Conclusion

Decision Tree Regressor achieved the best performance with:
- RMSE = 0.724234
- R² Score = 0.599732

This project demonstrates data preprocessing, feature scaling, model training, evaluation, and feature importance analysis using Machine Learning.
